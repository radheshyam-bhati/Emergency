# Support

## Questions and ideas

Use [GitHub Discussions](https://github.com/radheshyam-bhati/VAGRHUB/discussions)
for questions, setup help, and design ideas. If Discussions is unavailable, open
a feature request issue.

## Bugs

Open a bug report using the issue template. Include the version/commit,
reproduction steps, expected behavior, actual behavior, and relevant logs.
Remove secrets, personal data, and patient data before posting.

## Security issues

Do not open a public issue. See [SECURITY.md](SECURITY.md).

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md).

## Commercial or production use

This project is a simulation and is not offered as a production emergency
service. There is no support SLA. If you deploy it, you are responsible for
security, privacy, compliance, backups, and operational monitoring.
