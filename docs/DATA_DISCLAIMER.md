# Data and Safety Disclaimer

## Simulation only

Rapid Rescue Grid is a software demonstration. It is **not** an emergency
dispatch system, **not** a medical device, and **not** medical advice. Do not
use it to request, coordinate, or provide real emergency services.

## No real patient data

Do not enter, store, transmit, or process real patient data, personal health
information, or other sensitive personal data. The demo seed data is synthetic.
If you adapt this project for real data, you are responsible for a full privacy,
security, and compliance review.

## Hospital names

The seed data uses synthetic hospital names and fabricated capacity values.
Any resemblance to a real hospital or health system is coincidental. Do not
present the demo data as real operational information.

## Routing and map services

The demo may call public OSRM routing and public map tile services. Those
services receive coordinates and network metadata. Do not send real patient
locations or other sensitive data to public services. Use self-hosted or
contractually appropriate services for any real deployment.
